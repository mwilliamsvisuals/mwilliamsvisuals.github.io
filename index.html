US State Population Distribution

This page maps the total population of each state to compare how both tools build maps.

  • Tableau: Built instantly using drag-and-drop. It easily added clear number labels on top of each state.
  • R: Built using lines of code. It keeps the design clean, but defaults to shorthand math numbers (like 3e+07 for 30 million) unless you write extra code to format them.

Built in R (ggplot2)

Built in Tableau

Scatterplot: Fox Weight vs. Fur Length

This graph charts the physical traits of various fox species over two years (2024 and 2025) to see how weight compares to fur length.

  • Tableau: Uses hollow, ring-style data points by default. It makes tracking specific clusters straightforward but can feel a bit sparse without custom formatting.
  • R: Uses bold, solid colored points that stand out clearly against the grid. The labels for the years are automatically colored to match each specific fox species group perfectly.

Built in R (ggplot2)

Built in Tableau

Price Distribution by Diamond Cut

This graph compares diamond prices based on the quality of their cut, showing the lowest prices, highest prices, and the middle ranges.

  • Tableau: Shows the summary boxes clearly, but places individual data points as thick vertical purple columns in the background. It creates an interesting visual texture but can sometimes make individual extreme prices blend together.
  • R: Colors each box differently based on the cut grade using a clean color theme. It clearly stacks individual black outlier dots at the top, making it easy to spot exactly how high prices go for each category.

Built in R (treemapify)

Built in Tableau

Treemap: Makeup Brand Market Share

This visualization uses nested colored rectangles to compare market sizes across different cosmetic brands.

  • Tableau: Generates a clean, simple grid view instantly. It makes it very easy to overlay text labels displaying both the brand name and the exact data values (like MAC at 1,300).
  • R: Shines by allowing you to easily split the visual into separate regional panels (Europe and North America) using a coding concept called faceting. It makes comparing brand ratios across different continents incredibly easy.

🌟 Advanced Statistical Modeling in R

Visualizations famously elegant to generate programmatically in R, but restrictive or unavailable natively in standard drag-and-drop tools.

Programmatic Density Display (R ggplot2)

Violin Plot: Price Density by Cut

This advanced layout shows how diamond shapes mirror each other like instruments. Why R Excelled Here: It combines a box plot with a smooth curve. The wide sections show exactly where most diamond prices cluster, which Tableau cannot build natively without complex mathematical workarounds.

Probability Density Curve (R ggplot2)

Density Plot of Price by Diamond Cut

This chart stacks smooth continuous waves on top of each other to show price trends across different cuts. Why R Excelled Here: It blends transparent color layers perfectly so you can track where different diamond grades cross paths and overlap without blocking each other out.

Multivariate Correlation Matrix (R corrplot)

Correlogram: Fox Metric Correlations

This grid checks relationships between fox measurements like fur length, weight, and fur density. Why R Excelled Here: It builds a custom correlation matrix instantly. Strong relationships show as deep red boxes with clear math scores (like fur density vs fur length at 0.96), mapping out your full dataset in a single step.
